# Мой учебный проект Python "ООП"

## Описание:

Проект "OopProject" - это учебный проект на Python, содержащий последовательность выполнения домашних задач, 
начиная с раздела "4. Объектно-ориентированное программирование". 

Большая часть разработки проекта использует ООП-подход для создания своих сервисов, а также работы с данными, 
которые представляют собой сущности или объекты со своими параметрами и методами. Проработка использования классов 
и объектов на основе популярной темы e-commerce.
E-commerce  — электронная торговля, или электронная коммерция. На данном этапе разработки проекта не будет реализована 
система платежей, однако будет выполнена подготовка для того, чтобы появилось ядро для интернет-магазина. 

Редактирование содержания проекта сторонними пользователями не предусмотрено.

### Разработанные объекты, функции и модули:
- Определен класс Product [class Product](src/product.py) со следующими свойствами: название (name), 
описание (description), цена (price), количество в наличии (quantity). Добавлена инициализация так, 
чтобы каждый параметр был передан при создании объекта и сохранен.
- Определен класс Category [class Category](src/category.py) со следующими свойствами: название (name), 
описание (description), список товаров категории (products). Добавлена инициализация так, 
чтобы каждый параметр был передан при создании объекта и сохранен. Добавлены два атрибута класса. 
Доступ к этим атрибутам есть у каждого объекта класса, в них хранится общая информация для всех объектов. 
Эти атрибуты хранят в себе количество категорий и количество товаров. Атрибуты класса заполняются автоматически
при инициализации нового объекта.
- весь имеющийся код в файле [main.py](main.py) запускается без ошибок (с переносом части кода на [src](src)).
- Реализована загрузка данных по категориям и товарам из файла [JSON](data/products.json). 
Для этого разработана функция [read_json_data](src/utils.py), которая загружает данные из файла. 
И разработана функция [create_objects_from_json](src/utils.py), которая создает объекты классов.

### Тестирование:

- Разработан тест [test_category_init](tests/test_category.py) проверяющий корректность инициализации объектов
